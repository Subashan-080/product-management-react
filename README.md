# Anime Signup Page

A modern anime-themed signup page built using React and CSS.

## Features

- Anime-themed dark UI
- Responsive signup form
- Interactive input fields
- Hover and focus effects
- Modern button styling
- Clean and simple layout

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite
