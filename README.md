# React Product Management App

A responsive product management web application built with **React.js** and **TanStack Query**. The application demonstrates API data fetching, caching, routing, form handling, and interactive user interfaces.

## 🚀 Features

* Fetch and display products from an API
* Fetch and display user information
* Product details and product listing
* User signup form
* Client-side routing using React Router
* API requests using Axios
* Server-state management using TanStack Query
* Loading and error handling
* Toast notifications
* Responsive user interface

## 🛠️ Technologies Used

* React.js
* TanStack Query
* React Router
* Axios
* React Hot Toast
* JavaScript
* HTML5
* CSS3
* Vite

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Subashan-080/product-management-react.git
```

### 2. Open the project

```bash
cd product-management-react
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run locally using the Vite development server.

## 🏗️ Build for Production

```bash
npm run build
```

The production files will be generated inside the `dist` folder.
